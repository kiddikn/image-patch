# ImagePatch

macOS スクリーンショット注釈アプリ。
**複数枚の画像を 1 枚のキャンバスに並べて**、矢印・テキスト・モザイク・枠線・番号バッジを載せ、
最後に ⌘C でキャンバス全体をクリップボードへ。画像はどこにも送信しない（完全ローカル）。

- Swift / SwiftUI + AppKit、依存ライブラリなし
- 画面収録などの権限は不要（クリップボード経由で画像を受け取る）

## ビルドとインストール

```sh
make install   # ビルド → アイコン生成 → .app 作成 → /Applications へコピー
make run       # インストールして起動
make bundle    # build/ImagePatch.app を作るだけ
make uninstall # /Applications から削除
```

必要なもの: Xcode（Swift 6 系）と macOS 14 以降。

## 使い方

1. `⌘⇧4`（範囲）や `⌘⌃⇧4`（クリップボードへ直接）で macOS の標準スクショを撮る
2. ImagePatch で `⌘V` → キャンバスに画像が乗る。もう一度 `⌘V` で右隣に追加される
3. ツールを選んで注釈を描く
4. `⌘C` でキャンバス全体をコピー（`⌘S` で PNG 保存）

### ツール（修飾キーなしのショートカット）

| キー | ツール | 備考 |
|---|---|---|
| `V` | 選択 | ドラッグで移動、ハンドルでサイズ変更、空きをドラッグで範囲選択 |
| `A` | 矢印 | Shift で 45° 刻み |
| `L` | 直線 | Shift で 45° 刻み |
| `R` | 四角 | Shift で正方形、角丸スライダーあり |
| `E` | 丸 | 「塗り」で半透明の塗りつぶし |
| `T` | テキスト | クリックしてそのまま入力、Esc で確定。「文字背景」でプレート付き |
| `M` | モザイク | 下に描かれているピクセルを平均化。粒度をスライダーで調整 |
| `B` | 番号 | クリックで ①②③… と自動連番 |
| `C` | トリミング | ドラッグ後 Enter で確定、Esc で取消 |

### そのほかの操作

| 操作 | 内容 |
|---|---|
| `⌘V` | クリップボードの画像を追加（ファイルのコピーでも可・D&D も可） |
| `⌘C` | キャンバス全体をコピー |
| `⌘S` | PNG で保存 |
| `⌘Z` / `⌘⇧Z` | 元に戻す / やり直す |
| `⌘D` | 選択を複製 |
| `⌘A` | すべて選択 |
| `⌫` | 選択を削除 |
| 矢印キー | 1px 移動（Shift で 10px） |
| `⌘]` / `⌘[` | 前面へ / 背面へ |
| `⌘0` | 全体表示 |
| `⌘` + スクロール / ピンチ | ズーム |
| `⌘` + ドラッグ | キャンバスを掴んで移動 |
| `⌘N` | キャンバスを空にする |

「並べる」メニューから複数画像の**横並び / 縦並び / グリッド**に再配置できる。
画像の上に載っている注釈は一緒に移動する。

起動時にクリップボードに画像があれば読み込んだ状態で開く（不要なら `⌘Z`）。
ウィンドウを閉じると終了する。注釈が残ったまま終了しようとすると
「コピーして終了 / 破棄して終了 / キャンセル」を聞く。

## 動作確認

GUI を触らずに確かめられる 2 つのモード。

```sh
# レンダラ: 全ツールを 1 枚に描いて PNG 出力
.build/release/ImagePatch --selftest /tmp/selftest.png

# クリップボード読み取り: 見つかった画像の枚数とサイズを表示（無ければ exit 1）
.build/release/ImagePatch --clipcheck
```

## 構成

```
Sources/ImagePatch/
├── ImagePatchApp.swift        アプリ本体・メニュー・ショートカット
├── Model/
│   ├── Types.swift         色・ツール・要素・スタイル・文字計測
│   └── Doc.swift           キャンバスの状態、undo、レイアウト、トリミング
├── Render/
│   ├── Renderer.swift      CGContext への描画（画面表示と書き出しで共用）
│   ├── Pasteboard.swift    クリップボード入出力・PNG 保存・画像読み込み
│   └── SelfTest.swift      --selftest の中身
└── UI/
    ├── ContentView.swift   ツールバー・スタイル操作・ステータス
    └── CanvasView.swift    キャンバス（描画・マウス・キー・テキスト編集）
```

モザイクは「その時点までビットマップに描かれた内容を読み戻してブロック平均で塗り直す」方式なので、
画像の重なりや複数枚にまたがる領域でも正しく効く。画面表示と書き出しはまったく同じコードを通る。
